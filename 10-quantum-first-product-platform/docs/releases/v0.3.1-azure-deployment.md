# v0.3.1 — Azure recruiter deployment

## Current publication status

The release package, containers, local cross-layer acceptance and Bicep
compilation are verified. The live Azure apply is not yet verified because the
target subscription returned `ReadOnlyDisabledSubscription` during preflight.
No cloud resource or image publication was attempted after that stop rule.

## Delivered

- One public Azure Container App for the portal, control API, Swagger and
  OpenAPI contract.
- Consumption scaling bounded to zero or one replica in the existing shared
  Container Apps environment.
- Managed-identity pulls from the existing Project 7 ACR; no registry
  credentials are stored in the repository or deployment parameters.
- PostgreSQL 17 initialized from all five versioned migrations, with the API
  connected through a non-owner `p10_runtime` member and readiness verifying
  the RLS boundary.
- Synthetic public one-pager, PQC report and developer documentation fixtures
  recreated at every cold start for deterministic recruiter journeys.

## Evidence boundary

The deployment is a portfolio demo. Its database is ephemeral and its public
content is synthetic. It does not claim durable customer storage, customer
adoption, production uptime, quantum advantage, security certification or a
completed external identity-provider integration. Private workspace routes
remain bearer-protected and are not exposed as an anonymous demo workflow.

## Cost boundary

The release creates no new registry, Log Analytics workspace, file share or
managed database. The Container App scales to zero and at most one replica.
It reuses the existing Standard ACR, which remains billable, and Azure free
grants are usage allowances rather than an absolute zero-bill guarantee.
