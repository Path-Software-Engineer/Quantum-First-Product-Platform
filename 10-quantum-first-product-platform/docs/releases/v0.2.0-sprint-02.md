# Sprint 2 release evidence

Release: `v0.2.0-sprint-02-pqc-product-report-template`

## Delivered

- Product-version-linked PQC assessments protected by workspace RBAC and RLS.
- Declared RSA/ECC inventory with visible factor values and deterministic scores.
- Recommendation cards that retain dependencies and limitations.
- Required inventory, recommendation and five-phase roadmap before review.
- Independent reviewer rule and immutable SHA-256 report snapshots.
- Public projection without tenant identifiers or actor identities.
- Responsive, print-ready Docusaurus viewer with explicit evidence boundaries.
- OpenAPI 3.0 contract and Swagger coverage for every Sprint 2 operation.

## Claim boundary

The software organizes user-declared evidence. It does not scan production
systems, predict exploitability, certify compliance, choose a PQC algorithm or
claim that a migration succeeded. All acceptance fixtures are synthetic.

## Acceptance targets

- Unit tests cover validation and the scoring rubric.
- HTTP tests cover Swagger/OpenAPI exposure.
- PostgreSQL acceptance covers RBAC, RLS, independent review, lifecycle,
  immutable build, public projection and cross-tenant denial.
- Playwright covers empty, published and unavailable states on desktop/mobile,
  axe accessibility and horizontal overflow.
