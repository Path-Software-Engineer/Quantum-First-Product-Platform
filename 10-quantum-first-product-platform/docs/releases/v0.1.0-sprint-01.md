# Sprint 1 release evidence

Release: `v0.1.0-sprint-01-quantum-first-company-one-pager`

## Delivered

- PostgreSQL organization, workspace, membership and runtime-role RLS model.
- JWT identity, workspace RBAC and positive/negative tenant isolation.
- Versioned products, capabilities, use cases and commercial scenarios.
- Evidence-owned claims with independent review and approval workflow.
- Immutable public one-pager projection with source SHA-256 provenance.
- Versioned OpenAPI contract, JSON endpoint and interactive Swagger UI.
- Docusaurus portal with empty, published and unavailable artifact states.

## Acceptance

The strict gate performs a frozen install, lint, strict TypeScript builds,
unit tests, HTTP tests, disposable PostgreSQL integration, production portal
build, desktop/mobile Playwright flows, axe accessibility checks, dependency
audit and Git whitespace validation.

Browser data is explicitly synthetic and labeled as such. No testimonial,
customer, production metric or unsupported product capability is asserted.

## Security decision

Docusaurus packages are pinned to official canary `4.0.0-canary-6808` to
remove the high-severity transitive advisory present in stable `3.10.2` while
remaining inside the repository's Node 24 engine boundary. See
`docs/dependency-risk.md`.
